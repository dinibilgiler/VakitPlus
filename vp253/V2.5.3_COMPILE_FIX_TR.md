# Vakit+ V2.5.3 — Derleme düzeltmesi

Bu sürüm V2.5.2 derlemesinde görülen `RemoteOwnerPanel.kt` ve `RemoteOwnerRepository.kt` Kotlin hatalarını giderir.

- Repository extension fonksiyonları sınıf içine alındı.
- `context` erişimi tek sınıf üzerinden güvenli hale getirildi.
- Bildirim geçmişi lambda ifadeleri açık parametrelerle yeniden yazıldı.
- Bildirim istatistikleri çağrısı doğrudan sınıf metodu oldu.
- JVM 21 ayarları korunmuştur.
