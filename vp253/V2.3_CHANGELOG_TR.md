# Vakit+ V2.3 — Gelişmiş İçerik ve Bildirim Merkezi

- Merkezi bildirim geçmişi
- Zamanlanmış bildirimler
- Zamanlanan bildirimleri iptal etme
- Bildirim istatistikleri
- FCM konu hedefleme altyapısı
- Owner panelinde hemen gönder / zamanla / geçmiş / istatistik işlemleri
- Bildirim kampanyaları sunucu tarafında işlenir
- Zamanlayıcı 30 saniyede bir vadesi gelen kampanyaları kontrol eder
- FCM gönderimi için üretim Firebase Admin yapılandırması gerekir

FCM konu mesajları Admin SDK veya FCM HTTP v1 ile gönderilebilir. Kaynak: Firebase Cloud Messaging resmi dokümantasyonu.
