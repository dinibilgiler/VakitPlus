# Vakit+ V2.2 — Üretim Güvenliği

## Eklenenler
- Firebase App Check + Play Integrity istemci altyapısı
- Backend tarafında App Check token doğrulama modu (`REQUIRE_APP_CHECK=true`)
- Owner girişinde IP tabanlı brute-force rate limit: 15 dakikada 8 deneme
- Başarılı refresh kullanımında refresh token rotation
- Access token süresi 15 dakika
- Üretimde HTTPS zorunluluğu için deployment notları
- Gizli anahtarların kaynak koda yazılmaması için env tabanlı yapılandırma

## App Check'i üretimde açma
1. Firebase projesini oluşturun.
2. Android uygulamasını SHA-256 imza parmak iziyle kaydedin.
3. Play Console ile Cloud projesini bağlayın.
4. Firebase Console > Security > App Check > Android uygulaması > Play Integrity sağlayıcısını etkinleştirin.
5. Önce metrikleri izleyin, sonra enforcement açın.
6. Backend `.env` içinde `REQUIRE_APP_CHECK=true` yapın.

## Önemli
App Check, backend'i kötüye kullanıma karşı güçlendirir; tek başına mutlak güvenlik garantisi değildir. Owner yetkilendirmesi yine backend'de yapılır.

## Kaynaklar

- Firebase App Check: https://firebase.google.com/docs/app-check
