# Vakit+ V2.4

Bu sürüm, V2.3'teki bildirim/içerik merkezinin üzerine profesyonel Owner Dashboard ekler.

## Dashboard
- Cihazlar ve aktif cihazlar
- Bildirim istatistikleri
- Audit sayısı
- Bakım modu
- Merkezi duyuru

## Üretim notu
Bu proje kaynak olarak hazırlanmıştır. Gerçek Firebase projesi, Play Console bağlantısı, imzalama anahtarı ve HTTPS sunucu yapılandırması kullanıcıya aittir.
