# V2.1 Dağıtım

1. V2.0 projesini açın.
2. Backend'i çalıştırın ve mevcut `.env` ayarlarını koruyun.
3. `GET /v1/devices` Owner erişimiyle cihaz özetini döndürür.
4. `POST /v1/devices/register` FCM tokenını kaydeder/günceller.
5. `DELETE /v1/devices/{id}` Owner'ın cihaz kaydını kaldırır.
6. Üretimde JSON dosyası yerine PostgreSQL/Firestore gibi yönetilen veritabanı kullanın.
7. FCM kimlik bilgilerini yalnızca sunucu tarafında tutun.
