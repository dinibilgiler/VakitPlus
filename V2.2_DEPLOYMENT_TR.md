# V2.2 Dağıtım Notları

## Android
Firebase projesinden `google-services.json` eklenmeli ve Google Services Gradle plugin yapılandırılmalıdır. Bu dosya kaynak koda gizli sunucu anahtarı gibi değerlendirilmemeli; release yapılandırması SHA-256 ile Firebase'de kayıtlı olmalıdır.

## Backend
Üretimde:
- `REQUIRE_APP_CHECK=true`
- `OWNER_EMAIL`
- `OWNER_PASSWORD_HASH` + `OWNER_SALT`
- `JWT_SECRET` (en az 32 karakter; tercihen rastgele 64+ byte)
- Firebase Admin kimlik doğrulaması
- HTTPS reverse proxy
- Kalıcı veritabanı

kullanılmalıdır.
