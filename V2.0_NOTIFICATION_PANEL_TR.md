# Vakit+ V2.0 — Bildirim Yönetim Sistemi

## Yönetim panelinde artık bildirim bölümü var

### Yerel bildirim yönetimi
- İmsak, Güneş, Öğle, İkindi, Akşam, Yatsı ayrı ayrı aç/kapat.
- 0 / 5 / 10 / 15 / 30 dakika önce bildirim seç.
- Android uygulama bildirim ayarlarına geçiş.
- Yönetici panelinden cihaz üzerinde test bildirimi.

### Merkezi bildirim yönetimi
Owner panelinde:
- Bildirim başlığı
- Bildirim metni
- FCM konu adı
- Gönder

sunuluyor.

Üretim sunucusu Firebase Admin SDK ile FCM konu mesajı gönderecek. Firebase Admin SDK 14.4.0 ve Node.js 22+ kullanılır. Firebase tarafında Cloud Messaging API v1 etkinleştirilmeli ve sunucu Application Default Credentials / uygun servis hesabı ile yetkilendirilmelidir.

## Önemli
FCM gerçek gönderimi için Firebase projesi oluşturulmalı ve Android uygulamasına `google-services.json` eklenmelidir. Bu dosya proje kimliği gibi benzersiz ancak gizli olmayan yapılandırma bilgilerini içerir. Sunucu servis hesabı anahtarı ise APK içine kesinlikle konulmamalıdır.

Kaynaklar:
- Firebase Android setup: https://firebase.google.com/docs/android/setup
- FCM Android: https://firebase.google.com/docs/cloud-messaging/android/get-started
- FCM server: https://firebase.google.com/docs/cloud-messaging/server-environment
