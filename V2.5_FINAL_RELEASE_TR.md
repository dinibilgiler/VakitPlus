# Vakit+ V2.5 — Final Release

Bu sürüm geliştirme yol haritasının final paketidir.

## Yayın öncesi zorunlu işlemler
1. Android Studio Cloud / yerel Android Studio ile release build alın.
2. `google-services.json` kendi Firebase projenizden eklenir.
3. Firebase App Check / Play Integrity production'da etkinleştirilir.
4. FCM servis hesabı backend'e güvenli secret olarak eklenir.
5. Release keystore oluşturulur ve yedeklenir.
6. AAB imzalanır.
7. Gerçek cihazlarda bildirim, konum, kıble, vakit ve Kur'an testleri yapılır.
8. Play Console Data Safety ve içerik beyanları doldurulur.
9. Gizlilik politikası gerçek kullanılan veri akışına göre güncellenir.
10. Önce internal/closed testing, ardından production yayın yapılır.

## Önemli
Bu paket kaynak kodudur. Bu çalışma ortamında Android SDK/Gradle toolchain bulunmadığı için imzalı AAB/APK üretildiği iddia edilmez.

## Alternatif derleme ortamı
Yerel bilgisayar yetersizse Android Studio Cloud/Firebase Studio kullanılabilir. Proje GitHub'a yüklenerek bulut çalışma alanında açılabilir.
