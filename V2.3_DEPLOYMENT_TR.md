# V2.3 Dağıtım Notları

1. Firebase projesini oluşturun.
2. Android uygulamasını Firebase'e bağlayın ve google-services.json ekleyin.
3. Backend için Google Application Default Credentials veya güvenli servis hesabı yapılandırın.
4. FCM_PROJECT_ID değişkenini ayarlayın.
5. REQUIRE_APP_CHECK=true ile üretime geçin ve App Check token doğrulamasını etkin tutun.
6. Backend'i HTTPS arkasında çalıştırın.
7. Üretimde JSON dosyası yerine PostgreSQL/Firestore gibi yönetilen veritabanı kullanın.
8. Zamanlanmış bildirimler için backend sürecinin sürekli çalışması gerekir.
